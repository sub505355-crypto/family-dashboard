# 🐱🐢 인봉뿌 대시보드

공부도, 한마디도, 수다도 한 화면에서. 엄마 폰과 아이 태블릿에 맞춘 인봉뿌의 파스텔 가족 대시보드입니다.

**바로 열기 → https://sub505355-crypto.github.io/family-dashboard/**

## 들어 있는 기능

| | 기능 | 설명 |
|---|---|---|
| 🪙 | 공부 용돈 적립 | 공부 항목 버튼을 누르면 동전이 팡팡 튀며 잔액이 쌓이고, 금액·내역을 직접 고칠 수 있어요. |
| 💌 | 오늘의 한마디 | 엄마·아빠·현 각 한 줄씩 적고 **저장 / 삭제**. 기기에 저장되고, Firebase를 연결하면 가족과 함께 보여요. |
| 🖐️ | 하이파이브 | 오늘의 할 일을 모두 체크하면 고양이·거북이와 함께 축하 화면이 떠요. |
| 💬 | 가족 채팅방 | 엄마·아빠·현 프로필을 바꿔 대화, 고양이·거북이 스티커와 칭찬 한 마디. |
| ⏰ | 공부 타이머 & 태블릿 알람 | 10/20/30분·직접 입력 타이머, 태블릿 끄는 시각 알람(효과음 + 전체 화면 안내). |
| 🔒 | 가족 PIN 잠금(선택) | 링크를 아는 사람이 아무나 못 들어오게 4자리 PIN. 기본은 꺼져 있어요. |

## 저장 방식

- **기본값: 이 브라우저(localStorage)에 저장.** 설정 > "가족 실시간 동기화"가 비어 있으면 각 기기가 따로 저장됩니다.
- **가족 간 실시간 동기화(선택):** Firebase Realtime Database 주소를 넣으면 엄마 폰과 아이 태블릿이 같은 내용을 함께 봅니다.
  1. https://console.firebase.google.com 에서 프로젝트를 만들고 **Realtime Database**를 생성합니다.
  2. 규칙(테스트용):
     ```json
     { "rules": { "mongleFamily": { ".read": true, ".write": true } } }
     ```
     (공개 규칙이므로 가족 외에 알려지지 않게 URL을 관리하고, 오래 쓸 거라면 인증 규칙으로 바꾸는 것을 권장합니다.)
  3. 대시보드 ⚙️ 설정 → "가족 실시간 동기화"에 `https://<프로젝트>-default-rtdb.firebaseio.com` 을 넣고 **연결**을 누릅니다.
- PIN 잠금은 화면 잠금용 간단 장치입니다(브라우저 저장값을 아는 사람에게는 완전한 보안이 아닙니다).
- 태블릿 끄기 알람은 **대시보드 화면을 켜둔 동안** 울립니다(브라우저 정책상 화면을 닫으면 울리지 않아요).
